# 易考鸥 ExamO

**面向大学生的智能学习与期末备考助手 · AI Study Agent 项目**

[English](README_EN.md) · [官方产品主页](https://chenb5408-bit.github.io/ExamO/) · [功能清单](FEATURES.md) · [系统架构](ARCHITECTURE.md) · [智能体机制](AGENT.md)

易考鸥围绕学生自己的课程与学习资料，把资料解析、知识点整理、练习、批改、薄弱点诊断和持续复习连接起来。学生可以用教材、课件、复习资料、试卷或图片准备考试，并通过错题、闪卡和费曼讲解检验理解。

**实现状态｜2026-10-20**：核心学习流程已有代码实现；学习规划、自适应训练等部分能力需要相应配置。当前属于用户控制的学习工作流，结合模型辅助与规则决策；模型自主选择工具、长期自主执行学习目标仍在规划。本次核对未验证生产发布版本、开放范围或学习效果。

## 为谁解决什么问题

大学生的复习通常分散在课程安排、教材笔记、往年试卷和错题中。易考鸥帮助学生围绕具体课程组织资料，知道哪些内容需要练习、哪些知识点仍不稳定，以及下一次复习可以从哪里开始。

课程导入用于了解学生正在学习什么，维护课程时间、考试信息和应用内提示；**课程导入与上传课件、解析试卷是独立流程**，不会仅凭课程名称生成题库。

## 从资料到下一次复习

1. **明确目标**：选择课程，输入考试信息、可用学习时间与资料。
2. **解析与核对**：识别文件、图片或文本，由学生核对结果并确认保存。
3. **组织知识**：关联知识点和资料证据，形成可复习的学习上下文。
4. **制定与选择任务**：在启用相应能力后，根据考试时间、掌握情况和时间预算生成建议，学生选择开始。
5. **练习与反馈**：使用组卷、原题作答、批改、错题分析、闪卡或费曼讲解。
6. **评估与调整**：记录符合条件的答题与回忆反馈，更新学习状态，并在下次请求时重新计算训练和复习建议。

原试卷与题库沿原题路径使用，不把原题重新生成成另一套题；复习材料可用于生成新的练习。考试重点来自资料证据与系统分析，不能视为押题或真实考试概率。

## 智能体如何工作

ExamO 的 AI Study Agent 方向是把**感知—规划—执行—评估—调整**连接为持续的学习支持。

目前，资料和学习记录构成感知与记忆基础；规则与数据服务计算任务优先级、时间预算和复习建议；应用在用户选择后调用对应学习能力，反馈写回学习记录。下一轮建议可基于更新后的状态重新计算。

这是**用户控制、规则编排与模型辅助相结合的实现**。本次没有发现模型自主决定调用哪些工具并连续执行的完整闭环，也没有证据表明费曼、闪卡、课程提醒已全部被同一个自主调度器统一控制。详见 [AGENT.md](AGENT.md)。

## 产品取向

易考鸥以学生自己的课程和资料为学习上下文，而非只围绕固定题库。练习结果可以成为后续诊断、训练和复习建议的依据；闪卡支持主动回忆，费曼学习支持主动讲解。原题练习与 AI 生成练习保持来源区分。

这些是已发现实现与产品设计取向，不构成优于其他产品的性能结论、提分保证或市场独占性声明。若研究类似 Quizlet 或 StudyFetch 的产品，可参考[客观产品定位说明](docs/product-comparison.md)。

## 隐私与安全

- 核心小程序和后端源码继续保存在私有商业仓库；本仓库仅展示产品资料与公开索引。
- 只上传有权使用的学习资料，去除课表中的姓名、学号和无关信息。
- 资料处理和 AI 能力可能调用服务端及外部服务，不能从本介绍推断所有处理都在设备本地完成；以实际应用隐私告知与授权为准。
- AI 题目、解析、批改和学习建议可能有误，应结合教材、原试卷和教师要求核对。掌握度不是考试成绩预测。
- 安全漏洞请通过[私密报告入口](https://github.com/chenb5408-bit/ExamO/security/advisories/new)报告，不要公开密钥或学习资料。详见 [SECURITY.md](SECURITY.md)。
