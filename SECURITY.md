# 安全说明 / Security

此公开仓库只保存经审查的产品资料与已授权展示素材。核心源码继续私有，不接收真实凭据、用户数据、上传原件、数据库或内部部署信息。

## 安全报告

使用 [ExamO 私密漏洞报告](https://github.com/chenb5408-bit/ExamO/security/advisories/new)，需要 GitHub 登录。报告不会因为入口位于公开仓库就自动公开。不要在普通 Issue 中披露利用细节、真实密钥、个人信息或私有源码。

若报告入口不可用，先通过[维护者主页](https://github.com/chenb5408-bit)请求建立私密渠道，不在首次公开联系中附带敏感细节。

## 学习内容与隐私

只上传自己有权使用的资料；课表图应去除姓名、学号等无关信息。不要从公开介绍推断“所有识别均在设备本地完成”或“不会调用外部服务”；实际处理范围应以应用当时的隐私告知与授权为准。

AI 输出可能有误，需要与教材、题目原文和教师要求核对。资料中的功能状态、提醒边界与智能体规划不构成服务等级、合规认证或学习效果承诺。

本轮没有添加开源许可证；公开展示不等于授予源码、商标或素材再分发权。发现凭据泄露时，应先在服务方撤销并轮换，再处理传播范围。
