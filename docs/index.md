# 把学过的知识，变成真正的理解。

**ExamO · 易考鸥** 是面向课程学习与考试准备的 AI 伴学工具。围绕资料、练习、复习与讲解，为学习者组织连续的学习过程。

[功能介绍](features.html) · [技术架构](architecture.html) · [English](english.html) · [项目与联系](contact.html) · [安全说明](security.html)

## 学习有依据，复习有方向

- **从资料开始**：整理课程资料，衔接针对性练习。
- **在反馈中调整**：回顾作答结果，关注薄弱知识。
- **用回忆巩固**：错题复习与闪卡自评，检查掌握程度。
- **把理解讲出来**：费曼讲解与 AI 追问，发现概念之间的遗漏。

## 专注学习体验的技术架构

以微信小程序作为学习入口，后端服务连接资料解析、练习、复习和 AI 能力。持久化层保存学习过程数据；服务端管理供应商访问凭据。公开资料仅展示高层结构。
