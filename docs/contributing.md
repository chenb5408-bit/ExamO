# 反馈与合作 / Contributing

本仓库接受公开产品资料的事实修正、文案翻译、链接修复、可访问性建议和脱敏产品反馈。核心产品源码仍为私有，本仓库不接受核心业务代码、数据库、用户资料或部署文件。

## 提交反馈

通过 [Issues](https://github.com/chenb5408-bit/ExamO/issues/new/choose)说明页面、问题、期望结果和可公开的依据。合作意向可先提交不涉及商业机密的简要介绍，由维护者确认后建立适当渠道。

资料修正可提交 Pull Request。请区分已实现、待验收和规划能力；不新增未经核实的指标、客户案例、合作关系或产品发布日期。素材必须具有公开使用授权；截图先脱敏。

安全漏洞使用 [SECURITY.md](security.md) 指定的私密渠道。不得在公开 Issue、PR 或附件中披露密钥、学号、个人联系方式、内部地址和私有源码。

## English

We welcome factual corrections, translations, link fixes, accessibility suggestions and sanitized feedback on public product information. Core source remains private; do not submit application code, databases, user records or deployment files here.

Use [Issues](https://github.com/chenb5408-bit/ExamO/issues/new/choose) for public feedback or a non-confidential initial collaboration inquiry. Documentation pull requests should distinguish implemented, validation-required and planned capabilities, cite public evidence and include only authorized, sanitized assets. Use the private channel in [SECURITY.md](security.md) for vulnerabilities.

Submitting feedback does not grant access to private repositories or change the rights described in [NOTICE.md](notice.md).
