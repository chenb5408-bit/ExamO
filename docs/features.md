# 功能与使用场景

[返回首页](index.html) · [English](english.html)

| 学习阶段 | 产品能力 | 典型用途 |
| --- | --- | --- |
| 准备 | 课程与资料整理 | 集中管理一门课程的学习内容 |
| 学习 | 文档识别与练习组织 | 从资料进入练习，原题资料沿原题作答路径使用 |
| 练习 | 在线作答与结果反馈 | 发现知识点理解不足 |
| 复习 | 错题、闪卡与理解自评 | 考前回忆、日常巩固与薄弱点回顾 |
| 讲解 | 费曼练习与 AI 追问 | 像教初学者一样解释概念 |
| 持续改进 | 学习记录与复习安排 | 用学习反馈指导下一轮回顾 |

适用于课程备考、自学复盘与知识培训中的个人练习。AI 辅助内容需要学习者结合教材检查，不保证考试结果。
